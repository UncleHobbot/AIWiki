## Summary

Moonshot AI (Moonshot) is a leading Chinese AI company and the maker of the Kimi family of large language models and coding tools. Its Kimi product line spans general-purpose chat models (Kimi K2.6), coding-focused models (K2.7 Code), and developer tooling (Kimi Code CLI, Kimi Claw).

## Key Ideas

- One of China's top LLM labs, competing with DeepSeek, Qwen/Alibaba, and Z.AI in both general and coding model categories.
- The Kimi brand covers a full stack: flagship chat models, coding-specialized models, a CLI for terminal workflows, and an agent platform (Kimi Claw).
- Strong long-context capability is a recurring theme across Kimi models, enabling large-document and multi-file coding tasks.
- Offers API access and developer tooling alongside its consumer-facing Kimi assistant.
- Positioned as an open-weight-friendly lab, releasing model weights for several Kimi variants.

## Details

Moonshot AI built its reputation on the Kimi assistant, which emphasized very large context windows before most competitors matched them. The company has since expanded into coding: Kimi K2.7 Code targets software-engineering tasks and benchmarks, while the Kimi Code CLI brings the model into terminal-based developer workflows similar to Claude Code.

Alongside models, Moonshot ships Kimi Claw as an agent/productivity layer. The breadth of the lineup — chat, code, CLI, agents — places Moonshot among the few Chinese labs offering a vertically integrated developer stack, alongside its general-purpose model strengths.

## Краткое описание

Moonshot AI (Moonshot) — одна из ведущих китайских AI-компаний и создатель семейства больших языковых моделей и инструментов для кодинга Kimi. Линейка продуктов Kimi охватывает модели общего назначения (Kimi K2.6), модели, специализированные на кодинге (K2.7 Code), и инструменты для разработчиков (Kimi Code CLI, Kimi Claw).

## Ключевые идеи

- Одна из ведущих китайских LLM-лабораторий, конкурирующая с DeepSeek, Qwen/Alibaba и Z.AI как в общих, так и в кодинговых моделях.
- Бренд Kimi покрывает полный стек: флагманские chat-модели, модели, специализированные на кодинге, CLI для терминальных workflow и платформу агентов (Kimi Claw).
- Сильная способность к длинному контексту — повторяющаяся черта моделей Kimi, что enables работу с большими документами и мультифайловыми задачами кодинга.
- Предлагает API-доступ и инструменты для разработчиков наряду с потребительским ассистентом Kimi.
- Позиционируется как лаборатория, дружественная к открытым весам, выпуская веса для нескольких вариантов Kimi.

## Подробнее

Moonshot AI заработала репутацию на ассистенте Kimi, который делал акцент на очень больших контекстных окнах ещё до того, как большинство конкурентов смогли их повторить. С тех пор компания расширилась в кодинг: Kimi K2.7 Code нацелен на задачи программной инженерии и бенчмарки, тогда как Kimi Code CLI приносит модель в терминальные workflow разработчиков, аналогично Claude Code.

Наряду с моделями Moonship выпускает Kimi Claw как слой агентов/продуктивности. Широта линейки — chat, код, CLI, агенты — ставит Moonshot в число немногих китайских лабораторий, предлагающих вертикально интегрированный стек для разработчиков наряду с сильными моделями общего назначения.
