## 💡 Tips & Techniques

**[[dynamic-compute-budget-local-llm]]** — Let a local Qwen-35B-A3B model assign priorities to hard problems, then spawn independent parallel agents generating multiple solution attempts per problem. Result: 39.9% on HLE benchmark vs GPT-5.4-xHigh at 41.6%. Single iteration is the sweet spot; deeper recursion bloats context without proportionate gains.

**[[spec-driven-development-bmad]]** — Fabrice Monnier's practitioner account of the journey from vibe coding → BMAD framework → custom skills. Core insight: treating specs as the primary artifact (not code) fundamentally changes what AI agents can reliably deliver.

**[[claude-code-deferral-behavior]]** — Opus 4.7 has a documented task-skipping pattern: when given ambiguous or multi-step instructions it sometimes marks work done without executing all steps. Mitigation: explicit verification steps, checklist-based instructions, and `/verify` commands after each major phase.

**[[agentic-ai-coding-patterns-tornhill]]** — Adam Tornhill (author of "Your Code as a Crime Scene") on patterns that combine agent speed with quality: hotspot-driven refactoring, complexity-gated merges, and behavioral code analysis to focus agent effort on the highest-risk files.

**[[xp-practices-ai-assisted-development]]** — Paul Hammond (20+ years, 13 years XP) argues TDD, pair programming, continuous integration, and small releases are exactly the practices that prevent AI-generated code from accumulating undetected technical debt.

**[[test-driven-agentic-behaviours]]** — Antony Marcano demonstrates applying TDD to agentic AI itself: write a test that defines what the agent should do, verify the behavior, then iterate. Treats agent behavior as a first-class test target.

**[[claude-code-workflows-best-practices]]** — Official Claude Code docs distilled: treat context as your primary resource, always give Claude a way to verify its own work, use subagents for parallelism, and prefer CLAUDE.md over in-prompt instructions for persistent guidance.

**[[karpathy-claude-code-guidelines]]** — A single CLAUDE.md distilling Karpathy-inspired conventions: no lazy fixes, root-cause analysis, minimal impact changes, verification before done, and elegance checks before presenting work.

## 📚 Concepts Learned

**[[self-guided-self-play]]** *(Bailey, Wen, Dong, Hashimoto, Ma — arXiv 2604.20209, 2026)*
The breakthrough self-play algorithm that fixes the Conjecturer collapse problem plaguing LLM self-play. A third Guide role scores synthetic problems by relevance to real unsolved targets and naturalness, preventing degenerate problem generation. Applied to Lean4 formal theorem proving: a 7B model after 200 rounds of self-play solved more problems than a 671B baseline (pass@4). Surpasses the strongest RL baseline in fewer than 80 rounds.

**[[agi-impossibility-proof-debunked]]** *(Guerzhoy — Computational Brain & Behavior, April 2026)*
The formal academic takedown of Van Rooij et al.'s "Ingenia Theorem." The proof's core argument — that human-like intelligence via ML is NP-hard — relies on an unjustified swap between "human situation-behaviour distribution" and "all polytime-sampleable distributions." If you substitute ImageNet labels for human behaviour tuples everywhere, the proof equally "shows" that ImageNet classification is intractable. Three barriers make the proof irreparable: the undefinability of "human-like," the role of inductive biases, and the problem of defining data subsets.

**[[acdc-agent-centric-development-cycle]]** — Edgar Kussberg's framework for restructuring the entire SDLC around AI agents rather than treating agents as bolt-ons. Shifts the organizational model from humans-with-AI-assist to humans-supervising-AI-doing.

**[[new-organizational-models-ai-agents]]** — Matthias Patzak (AWS Executive in Residence) on the org-level changes required: moving from human-centric hierarchies to human-AI hybrid operating models, with implications for team structure, decision authority, and accountability.

**[[llm4sr-survey]]** — First systematic survey of LLMs across the full scientific research lifecycle: hypothesis generation, literature review, experiment design, code generation, peer review, and knowledge synthesis. Maps current capability gaps and forecasts near-term automation potential by research phase.

## 📚 Изученные концепции

**[[self-guided-self-play]]** *(Bailey, Wen, Dong, Hashimoto, Ma — arXiv 2604.20209, 2026)*
Прорывной алгоритм самоигры, решающий проблему «коллапса Конъюнктора». Роль Гида оценивает синтетические задачи по релевантности реальным нерешённым задачам и естественности, предотвращая вырожденную генерацию задач. При замене человеческого поведения на метки ImageNet получаем тот же абсурдный вывод о вычислительной неразрешимости ImageNet.
