## Summary
A community-curated collection of 1000+ agent skills from official engineering teams (Anthropic, Google, Vercel, Cloudflare, Sentry, Microsoft, and more), compatible with Claude Code, Codex, Gemini CLI, Cursor, OpenCode, and other coding agents.

## Key Ideas
- Hand-picked, not AI-generated: focuses on real-world skills created and used by actual engineering teams, not bulk-generated content.
- Official skill bundles from: Anthropic, Google Labs (Stitch), Vercel, Cloudflare, Netlify, Sentry, Expo, Hugging Face, Figma, Trail of Bits (security), Microsoft Azure, Venice.ai, VoltAgent, HashiCorp Terraform, Typefully, and more.
- Anthropic's own published skills include: `pdf`, `frontend-design`, `webapp-testing`, `skill-creator`, `mcp-builder`, `web-artifacts-builder`, `pptx`, `xlsx`, `docx`, and others.
- Maintained by the VoltAgent team with community contributions; hosted at `officialskills.sh` (300k+ monthly views).
- Compatible harnesses: Claude Code, Codex CLI, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf.

## Details
The repository serves as a single discovery point for production-quality agent skills. Each skill bundle is organized by team and provides domain-specific knowledge for a particular platform, framework, or workflow.

Notable team skill bundles:
- **Cloudflare**: Workers, Durable Objects, D1, R2, KV, Email Routing, Sandbox SDK
- **Sentry**: 20+ skills covering setup for every major language/framework, issue fixing, alerts, code review
- **Microsoft Azure**: 133 skills across 6 languages for Azure SDK and AI Foundry development
- **Google Workspace CLI**: Skills for managing Google Workspace services via `gws` CLI
- **Trail of Bits**: Security-focused skills for code auditing
- **Expo**: Mobile app building, deploying, and debugging

This is the primary resource for finding official, quality-verified agent skills as the ecosystem grows rapidly.

## Краткое описание
Курируемая сообществом коллекция из 1000+ agent skills от официальных команд разработчиков (Anthropic, Google, Vercel, Cloudflare, Sentry, Microsoft и других), совместимая с Claude Code, Codex, Gemini CLI, Cursor, OpenCode и другими агентами.

## Ключевые идеи
- Отобрано вручную, не сгенерировано ИИ: только реальные навыки от настоящих инженерных команд, без массово сгенерированного контента.
- Официальные пакеты навыков от: Anthropic, Google Labs, Vercel, Cloudflare, Netlify, Sentry, Expo, Hugging Face, Figma, Trail of Bits, Microsoft Azure, Venice.ai, VoltAgent, HashiCorp, Typefully и других.
- Собственные опубликованные навыки Anthropic включают: `pdf`, `frontend-design`, `webapp-testing`, `skill-creator`, `mcp-builder`, `web-artifacts-builder`, `pptx`, `xlsx`, `docx` и другие.
- Поддерживается командой VoltAgent при участии сообщества; хостится на `officialskills.sh` (300k+ просмотров/месяц).
- Совместимые агенты: Claude Code, Codex CLI, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf.

## Подробнее
Репозиторий служит единой точкой открытия высококачественных agent skills. Каждый пакет организован по команде и предоставляет специализированные знания для конкретной платформы, фреймворка или рабочего процесса.

Ключевые пакеты навыков по командам:
- **Cloudflare**: Workers, Durable Objects, D1, R2, KV, Email Routing, Sandbox SDK
- **Sentry**: 20+ навыков для настройки на всех основных языках/фреймворках, исправления ошибок, алертов и ревью кода
- **Microsoft Azure**: 133 навыка на 6 языках для Azure SDK и AI Foundry
- **Trail of Bits**: навыки безопасности для аудита кода
- **Expo**: создание, деплой и отладка мобильных приложений

Это основной ресурс для поиска официальных, проверенных agent skills по мере быстрого роста экосистемы.
