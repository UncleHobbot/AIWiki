## Summary
Runware made OpenClaw hosting completely free — one-click deploy with no hosting subscription. Users pay only for the tokens their agents actually consume (fully PAYG). Still in beta.

## Key Ideas
- Hosting is now completely free; no subscription or hosting fee
- One-click deployment removes setup/hosting/updates barrier
- Fully pay-as-you-go: only pay for tokens agents actually use
- Access to leading closed and open-source LLMs
- Still in beta — expect rough edges

## Details
OpenClaw is an open-source agent framework that previously required users to manage their own hosting or pay for a hosting tier. Runware's decision to make hosting free eliminates the biggest adoption barrier — setup, maintenance, and fixed hosting costs. Users now only pay for inference tokens their agents consume, making it cost-effective for experimentation and low-volume use cases.

The move positions OpenClaw against managed agent platforms by removing the infrastructure tax. Developers can deploy agents immediately without provisioning servers, configuring environments, or managing updates. Access to both closed-source (GPT, Claude) and open-source (Llama, Qwen) models through a single interface further reduces friction.

## Краткое описание
Runware сделала хостинг OpenClaw полностью бесплатным — развёртывание в один клик без абонентской платы за хостинг. Пользователи платят только за токены, которые их агенты фактически потребляют (полностью PAYG). Всё ещё в бета-версии.

## Ключевые идеи
- Хостинг теперь полностью бесплатен; нет подписки или платы за хостинг
- Развёртывание в один клик устраняет барьер настройки, хостинга и обновлений
- Полная оплата по факту использования: платите только за токены, которые агенты реально расходуют
- Доступ к ведущим закрытым и open-source LLM
- Всё ещё бета — возможны шероховатости

## Подробнее
OpenClaw — open-source фреймворк для агентов, который ранее требовал от пользователей самостоятельного управления хостингом или оплаты тарифа хостинга. Решение Runware сделать хостинг бесплатным устраняет главный барьер внедрения — настройку, поддержку и фиксированные расходы на инфраструктуру. Пользователи теперь платят только за инференс-токены, которые их агенты потребляют, что делает платформу экономически эффективной для экспериментов и сценариев с небольшим объёмом использования.

Этот шаг позиционирует OpenClaw против управляемых платформ агентов, убирая «инфраструктурный налог». Разработчики могут развернуть агентов немедленно без выделения серверов, настройки окружения или управления обновлениями. Доступ к закрытым (GPT, Claude) и open-source (Llama, Qwen) моделям через единый интерфейс дополнительно снижает трение.
