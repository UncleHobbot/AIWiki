## Summary
Fabrice Monnier shares his personal journey from vibe coding (magical but fragile) to spec-driven development with BMAD and eventually custom skills — showing how to move from prototype-generating AI to production-quality AI-assisted development.

## Key Ideas
- **Vibe coding is great for generation, painful for iteration**: generating a portfolio tracker from scratch worked brilliantly; trying to enhance it caused everything to break — a common early experience.
- **BMAD framework as a bridge**: the BMAD (Breakthrough Method for Agile AI-Driven Development) methodology introduces structure — specs, tasks, context — that constrains AI within a disciplined workflow.
- **Custom skills as the next level**: beyond BMAD, creating project-specific skills that encapsulate domain knowledge and workflow patterns allows the AI to work with less correction.
- **The prototype trap**: vibe coding naturally produces prototype-quality code (spaghetti after a few iterations); spec-driven approaches produce architecture that can be evolved.
- **Progressive sophistication**: the journey is incremental — start with vibe coding, hit its limits, adopt BMAD, then customize further; don't try to skip to the end.

- [~9:00] BMAD introduced as the next step: structure that addresses the fragility of pure vibe coding.

## Краткое описание
Фабрис Монье рассказывает о своём личном пути от vibe coding (волшебного, но хрупкого) к spec-driven разработке с BMAD и далее к custom skills — показывая, как перейти от AI, генерирующего прототипы, к AI-ассистированной разработке продакшн-качества.

## Ключевые идеи
- **Vibe coding отлично работает для генерации, болезненно для итераций**: создание трекера портфолио с нуля работало блестяще; попытки улучшить его приводили к поломке всего — типичный ранний опыт.
- **Фреймворк BMAD как мост**: методология BMAD (Breakthrough Method for Agile AI-Driven Development) вводит структуру — спецификации, задачи, контекст — которая ограничивает AI в рамках дисциплинированного рабочего процесса.
- **Custom skills как следующий уровень**: помимо BMAD, создание проектно-специфичных навыков, инкапсулирующих доменные знания и паттерны рабочего процесса, позволяет AI работать с меньшим числом коррекций.
- **Ловушка прототипа**: vibe coding естественным образом производит код прототипного качества (спагетти после нескольких итераций); spec-driven подходы производят архитектуру, которую можно развивать.
- **Прогрессивная усложнённость**: путь инкрементален — начни с vibe coding, столкнись с его пределами, перейди к BMAD, затем настрой дальше; не пытайся пропустить этапы.
