- Agent lifecycle: session start → user prompt → reasoning → tool calls → sub-agent → response → session end
- Hook events: SessionStart, UserPromptSubmitted, PreToolUse (blocking), PostToolUse, SubAgentStart, SubAgentStop, SessionEnd, ErrorOccurred
- Hook format: JSON files in .github/hooks/ or user profile .copilot/.cloud folders
- Hooks fire deterministically (not model-driven); good for gates and context injection
- PreToolUse can DENY tool calls (blocking hook) — key difference from others
- Practical ESLint gate: use PreToolUse to run linting on file writes; deny if lint fails; forces model to write correct code before moving on
- Context injection via SessionStart: inject env info (Node version, etc.) to avoid model making tool calls for it
