## Summary
Ollama is a local LLM inference platform that lets you run large language models on your own hardware. Ollama Cloud extends this with managed inference capabilities, enabling seamless switching between local and cloud model execution.

## Краткое описание
Ollama — платформа локального вывода LLM, позволяющая запускать языковые модели на собственном оборудовании. Ollama Cloud расширяет возможности управляемым выводом, обеспечивая бесшовное переключение между локальным и облачным выполнением моделей.
