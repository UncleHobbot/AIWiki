## Summary
Matt Pocock's open-source glossary of 100+ AI coding terms (1.9k stars), organized into seven thematic sections. Translates confusing AI jargon into plain English with usage examples and cross-references.

## Key Ideas
- **Seven sections** covering model fundamentals, context windows, tools, failure modes, handoffs, memory systems, and work patterns
- **Usage examples** for every term — not just definitions but how to apply them
- **Cross-references** between related concepts and explicit distinctions between similar-sounding terms
- **Failure modes section** is uniquely practical: terms like "attention degradation," "hallucination," and context-related errors explained from a developer's perspective
- **Work patterns section** covers human-in-the-loop, AFK sessions, and vibe coding as first-class vocabulary

## Details
Created by Matt Pocock (aihero.dev) as a companion to his skills repo. The underlying motivation: "AI coding can feel like it's just for experts. Unexplained jargon. Mysterious failures." By naming phenomena precisely, developers can diagnose problems faster and communicate with each other more effectively.

The dictionary also draws a clear distinction between **model capabilities** (what the LLM itself can do) and **harness functionality** (what the scaffolding around the model adds). This distinction prevents a common class of confusion where developers blame the model for a harness failure or vice versa.

The glossary is especially useful as onboarding material for teams adopting AI-assisted development — it establishes shared language that reduces misunderstandings in code reviews and planning discussions.

## Краткое описание
Открытый глоссарий от Мэтта Покока с 100+ терминами AI-разработки (1.9k звёзд), организованный в семь тематических разделов. Переводит запутанный жаргон ИИ на простой язык с примерами использования.

## Ключевые идеи
- **Семь разделов**: основы моделей, контекстные окна, инструменты, режимы отказа, handoff, системы памяти и паттерны работы
- **Примеры использования** для каждого термина — не просто определения, а практическое применение
- **Перекрёстные ссылки** между связанными концепциями и явные различия между похожими терминами
- **Раздел режимов отказа** особенно практичен: «деградация внимания», «галлюцинации» и связанные с контекстом ошибки разъяснены с точки зрения разработчика
- **Раздел паттернов работы** охватывает human-in-the-loop, AFK-сессии и vibe coding как полноценные термины

## Подробнее
Словарь проводит чёткое различие между **возможностями модели** (что может делать сам LLM) и **функциональностью harness** (что добавляет инфраструктура вокруг модели). Это разграничение устраняет распространённый класс заблуждений, когда разработчики винят модель в проблемах harness и наоборот.

Глоссарий особенно полезен как учебный материал для команд, внедряющих AI-разработку — он устанавливает общий язык, снижающий количество недопониманий при код-ревью и планировании.
