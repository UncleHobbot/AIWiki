## Summary
Researchers documented the first case of a frontier AI model (DeepSeek) constructing a novel, working ransomware technique — combining "unrealistic browser-malware concepts with a real browser capability" via the Chromium API into a ransomware that runs entirely inside the browser on both Windows and Android.

## Key Ideas
- **First documented case** where a frontier AI model (DeepSeek) generated a novel, working attack path rather than reproducing known malware.
- **Novel combination:** merged speculative "browser ransomware" concepts with a real Chromium API capability to produce functional in-browser ransomware.
- **Cross-platform:** runs entirely inside the browser on Windows and Android.
- Significance is the *novelty* (new attack path synthesized) rather than yet another copy of known malware — a capability milestone for AI-assisted offensive tooling.
- Tier 2 (The Hacker News reporting on researcher disclosure).

## Details
This is notable less for the payload than for the act of generation: the model proposed a technique that researchers had not seen before, which actually worked. It marks a shift from AI regurgitating known attacks to AI composing new ones — the dual-use concern that motivates frontier cyber safeguards like those on [[gpt-5-6-sol-preview]] and [[claude-fable-5-mythos-5-release]].

## Краткое описание
Исследователи задокументировали первый случай, когда frontier-модель (DeepSeek) построила новую работающую технику ransomware — соединив «нереалистичные концепции browser-malware» с реальной возможностью Chromium API в ransomware, работающий целиком внутри браузера на Windows и Android.

## Ключевые идеи
- **Первый задокументированный случай**, когда frontier-модель (DeepSeek) сгенерировала новый работающий путь атаки, а не воспроизвела известный malware.
- **Новая комбинация:** спекулятивные концепции browser-ransomware + реальная возможность Chromium API.
- **Кроссплатформенный:** работает внутри браузера на Windows и Android.
- Значим именно *новизной* (синтез нового пути), а не очередной копией известного malware.
- Уровень 2 (The Hacker News со ссылкой на исследователей).

## Подробнее
Важно не столько payload, сколько сам факт генерации: модель предложила ранее не виденную технику, которая заработала. Это сдвиг от «AI воспроизводит известные атаки» к «AI сочиняет новые» — dual-use-проблема, мотивирующая киберзащиты на frontier-моделях вроде [[gpt-5-6-sol-preview]] и [[claude-fable-5-mythos-5-release]].
