## Summary
`freebuff` is a 100% free CLI coding agent that lets you choose from top open models including DeepSeek v4 Pro/Flash, Kimi K2.6, and MiniMax M2.7 — installed with a single npm command.

## Key Ideas
- **Completely free:** No paid API key required — uses free tiers or open access of the supported models.
- **Model choice:** DeepSeek v4 Pro, DeepSeek v4 Flash, Kimi K2.6, MiniMax M2.7 — all selectable.
- **Single install:** `npm i -g freebuff`
- **CLI agent:** Designed as a terminal coding agent in the spirit of Claude Code but with open/free model backends.
- **DeepSeek v4 Pro quality:** Based on benchmarks elsewhere in this wiki, DeepSeek v4 Pro scores ~77/100 on complex coding tasks — capable for most day-to-day work.

## Details
Released by @jahooma (James Grugett) in May 2026. The tool positions itself as a free alternative to paid coding agents like Claude Code, targeting developers who want capable AI coding assistance without subscription costs.

The availability of models like DeepSeek v4 Pro (competitive with mid-tier paid models) and MiniMax M2.7 makes freebuff a viable option for exploratory coding, prototyping, or teams without budget for commercial agents.

No detailed documentation was available at announcement beyond the install command and model list.

## Краткое описание
`freebuff` — полностью бесплатный CLI-агент для кодирования, позволяющий выбирать из топовых открытых моделей: DeepSeek v4 Pro/Flash, Kimi K2.6 и MiniMax M2.7. Устанавливается одной командой npm.

## Ключевые идеи
- **Полностью бесплатно:** Не требует платного API-ключа — использует бесплатные уровни или открытый доступ поддерживаемых моделей.
- **Выбор модели:** DeepSeek v4 Pro, DeepSeek v4 Flash, Kimi K2.6, MiniMax M2.7 — все доступны для выбора.
- **Простая установка:** `npm i -g freebuff`
- **CLI-агент:** Создан как терминальный агент для кодирования в духе Claude Code, но с открытыми/бесплатными бэкендами моделей.

## Подробнее
Выпущен @jahooma (Джеймс Груггет) в мае 2026 года. Инструмент позиционируется как бесплатная альтернатива платным агентам для кодирования вроде Claude Code, ориентированная на разработчиков, которым нужна мощная AI-помощь в программировании без подписки.

Доступность таких моделей, как DeepSeek v4 Pro (конкурентоспособен с моделями среднего уровня) и MiniMax M2.7, делает freebuff жизнеспособным вариантом для исследовательского кодирования, прототипирования или команд без бюджета на коммерческих агентов.
