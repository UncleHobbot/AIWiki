## Summary

Microsoft's official beginner course for building AI agents — 12 lessons covering fundamentals with Python code samples using Microsoft Agent Framework and Azure AI Foundry Agent Service V2. Available in 50+ languages. Part of a curriculum that includes Generative AI for Beginners (21 lessons) and Azure/Edge/MCP/Agents courses.

## Key Ideas
- **12 standalone lessons:** Each covers a separate topic — start anywhere, no strict ordering required
- **Microsoft Agent Framework + Azure AI Foundry V2:** All code samples use Microsoft's agent framework with Azure AI Foundry Agent Service
- **50+ language translations:** Including Russian, Chinese (Simplified/Traditional), Japanese, Korean, Arabic, Hindi
- **Code samples folder:** Each lesson includes runnable Python code in code_samples/
- **OpenAI-compatible alternatives:** Some samples support alternative providers like MiniMax (204K context models)
- **Companion courses:** Generative AI for Beginners (21 lessons), plus Azure/Edge/MCP/Agents tracks
- **Community:** Dedicated Discord channel in Microsoft Foundry Discord for Q&A
- **Sparse checkout option:** 50+ translations increase repo size; use sparse checkout to skip them

## Details

This is Microsoft's canonical educational resource for AI agent development. It targets developers new to agentic systems and provides a structured path from basics to practical implementation. The course uses Azure AI Foundry as the primary platform but is designed to teach transferable concepts.

For our wiki, this is a Tier 2 educational resource from a major tech company — useful as a reference for beginners entering the AI agent space.

## Краткое описание

Официальный курс Microsoft для начинающих по созданию AI-агентов — 12 уроков, охватывающих основы с примерами кода на Python с использованием Microsoft Agent Framework и Azure AI Foundry Agent Service V2. Доступен на 50+ языках, включая русский.

## Ключевые идеи
- **12 независимых уроков:** Каждый охватывает отдельную тему — можно начинать с любого
- **Microsoft Agent Framework + Azure AI Foundry V2:** Все примеры используют фреймворк Microsoft
- **50+ языков перевода:** Включая русский, китайский, японский, корейский, арабский, хинди
- **Примеры кода:** Каждый урок включает исполняемый Python-код в папке code_samples/
- **Совместимые альтернативы:** Некоторые примеры поддерживают OpenAI-совместимые провайдеры (MiniMax, 204K контекст)
