## Summary

All 7 free Anthropic Academy core practitioner courses reviewed after completing them in one weekend (~12 hours total). Not all courses suit all learners — some have sections worth skipping. Three learning roadmaps provided: for beginners, developers/builders, and security practitioners.

## Key Ideas

- **All 7 courses are free** at anthropic.skilljar.com — total time ~12 hours
- **"AI Fluency: Frameworks and Foundations"** is the standout course recommended for everyone regardless of background — uniquely covers the "diligence" aspect of AI fluency
- **"Building with the Claude API"** (8 hours) is the most comprehensive technical course — covers the full Claude API stack including prompt caching, extended thinking, and agents
- **MCP courses**: take "Intro" first, get hands-on experience, then come back to "Advanced Topics" — don't jump straight to Advanced
- **"Claude Code in Action"** is essential for developers but skippable for non-developers
- **"Introduction to Agent Skills"** is short (no exercises) but fine for anyone building with Claude Code

## Details

Course-by-course breakdown:

**1. Claude 101** — High-level overview, features, skills/connectors. Useful reference but heavy reading, light exercises. Skip if you're already using Claude daily.

**2. AI Fluency: Frameworks & Foundations** — The gem of the lineup. Covers how humans actually interact with AI, prompting techniques, and an underrated section on "diligence" as part of AI fluency not found elsewhere. Exercise-heavy. Applies to any AI tool, not just Claude.

**3. Intro to MCP** — Beginner-friendly MCP breakdown: server, client, resources, SDK. Requires basic coding knowledge. Files provided for follow-along. Good foundational course.

**4. MCP Advanced Topics** — Sampling, streamable HTTP transport, message types, file system. Dense and technical. Best interactive modules of all 7 courses. Only for active MCP builders; come here after hands-on experience with Intro.

**5. Claude Code in Action** — Tool use internals, GitHub Actions, Claude SDKs, practical tips. Specific and practical with real commands. Essential for developers.

**6. Building with the Claude API** — 8 hours covering: setup, models, temperature, streaming, prompt engineering, tool use, RAG, text embeddings, prompt caching, extended thinking, workflows, agents. Most comprehensive. Skip the prompt engineering sections if you took AI Fluency.

**7. Intro to Agent Skills** — Short videos on writing and troubleshooting Claude Code skills. No exercises. Watch regardless of level; just don't expect hands-on.

## Краткое описание

Обзор всех 7 бесплатных курсов Anthropic Academy после прохождения их за один уикенд (~12 часов). Не все курсы подходят всем — некоторые разделы можно пропустить. Три роадмапа: для новичков, разработчиков и специалистов по безопасности.

## Ключевые идеи

- **Все 7 курсов бесплатны** на anthropic.skilljar.com — суммарно ~12 часов
- **"AI Fluency: Frameworks and Foundations"** — лучший курс для всех уровней, единственный охватывает "дилижентность" как компонент AI-грамотности
- **"Building with the Claude API"** (8 часов) — самый полный технический курс: prompt caching, extended thinking, агенты
- **Курсы по MCP**: сначала "Intro", затем практика, потом "Advanced" — не прыгайте сразу в Advanced
- **"Claude Code in Action"** — обязателен для разработчиков, необязателен для остальных
- **"Introduction to Agent Skills"** — короткий курс без упражнений; подходит для любого уровня

## Подробнее

Курс "AI Fluency" уникален тем, что охватывает не Claude как продукт, а то, как люди взаимодействуют с AI в принципе. Раздел о "дилижентности" — умении критически проверять выходные данные AI — автор называет недооценённым и уникальным для всего лайнапа.

"Building with the Claude API" охватывает полный стек: от базовой настройки до streaming, RAG, text embeddings, prompt caching, extended thinking и агентов. Наиболее ценен для разработчиков, которые хотят выйти за рамки базового использования Claude API.

- [9:12] Роадмап для разработчиков: Claude 101 → AI Fluency → Claude API → MCP → Claude Code → Skills
- [9:54] Роадмап для безопасников: AI Fluency → Claude 101 → MCP Intro → Claude API
